### `03` &nbsp; 🔗 URL Shortener &nbsp; · &nbsp; Production Backend Service
> *First project after learning Node & Express — built it properly*

A full backend service for shortening URLs — not a toy project. Register, log in,
create custom or auto-generated short codes, and redirect via HTTP 301. Deliberate
architecture: **PostgreSQL over MongoDB** for relational integrity, Drizzle ORM for
type-safe queries, custom salt-based password hashing, and Zod validation at every
boundary. This is where backend development clicked as a discipline.

[**View Repository →**](https://github.com/Abdul-wahab113/URLSHORTNER-Node-Express)

`Node.js` `Express.js` `PostgreSQL` `Drizzle ORM` `JWT` `Zod` `Docker` `nanoid`

### `04` &nbsp; 🔌 Supply Chain Route Optimizer &nbsp; · &nbsp; Systems Design
> *A DSA course project that became a client-server architecture problem*

Assigned as a desktop app with no guidance on connecting a C++ backend to a Java
frontend. I designed the architecture from scratch: a **C++ backend server** handling
all routing logic, a **Java client** frontend, connected over **Windows Socket
Programming** with JSON as the data exchange format. The first time client-server
architecture clicked for me — from building it, not reading about it.

[**View Repository →**](https://github.com/Abdul-wahab113/SupplyChainRouteOptimizer)

`C++` `Java` `Socket Programming` `Client-Server` `JSON` `DSA`
